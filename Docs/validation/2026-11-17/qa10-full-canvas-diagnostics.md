# 전체 화면 조준점 QA10 검증 준비

QA9 실제 8행에서 카메라 중심 `(1170,540)`과 조준점 `(1220,540)`이
갈렸습니다. 카메라는 전체 화면, 조준점은 왼쪽100px을 제외한 안전 영역의
중앙을 사용했습니다. [원인과 최소 UI 수정](crosshair-safe-area-centre-candidate.md)을
새 Android 후보에서 확인하기 위해 진단을 QA10으로 파생합니다.

`LocalQa10GeometryDiagnostics`는 QA9의 클래스/로그/소유 객체 이름과
앱 버전 `1.0.197-qa10`/versionCode10 식별만 바꿉니다. GUID는 승계합니다.
Android와 `SUDDEN_FORCE_LOCAL_QA`가 함께 정의되고 정확한 별도 localqa 앱,
접속 세대와 본인 카메라가 일치할 때만 최대8행을 읽습니다.
300초 TTL·종료/씬 변경 해제·384B 청크·850B 로그 상한·행 SHA를 유지합니다.
조준점이 전체 Canvas의 직접 자식이면 SafeArea 부모와 캐시가 없는 것이 정상입니다.
사격·카메라·UI 상태를 수정하지 않습니다.

소스 독립 검토는 허용 식별자 외 전체 바이트 일치와28개 정적 항목을
확인했습니다. 비활성 견본과 원 QA9 실패/관측은 외부 검증 자료에 보존합니다.
이 커밋은 Unity 컴파일·새 APK·실기기 정렬 성공을 의미하지 않습니다.

다음 단계는 새 공개 소스 동결 → 별도 export/서명 → 설치 보존 확인 →
사전에 제어기를 준비한 짧은 두 피어 경기의 같은 프레임8행입니다.
실제 발사 tick·다른 화면비/회전·자연 collector 해제·제품 전체 수용과 구분합니다.
운영 code34/1.0.196/release12와 원장196,2,34는 변경하지 않습니다.

Refs #407, #401; Draft PR406의 후속 검증입니다.
