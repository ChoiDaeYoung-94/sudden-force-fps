# 로컬 QA11 재장전 프레이밍 후보

Refs #410

QA10 소스 `05f949116cd33512a622670eb059a90ab345f4a4`에서 재장전 중 왼쪽으로 최대 4cm 당기던 X 위치 항 하나만 제거합니다. 조준점의 전체 Canvas 기준 배치와 기존 43속성 로컬 QA 프로토콜은 유지합니다. 제품 변경은 별도 main 대상 PR로 검토하며 이 QA 스택 전체를 main에 병합하지 않습니다.

예정 로컬 산출물은 `com.AeDeong.SuddenForceFPS.localqa`, `1.0.197-qa11`, code11, ARM64입니다. Play 코드34/1.0.196/릴리스12 및 원장196,2,34는 그대로입니다. 새 export·Gradle·서명·기기 검증 전에는 생성·통과로 표시하지 않습니다.

QA10 전용 geometry 진단은 `Application.version == "1.0.197-qa10"` 검사로 진입 전에 중단되므로 QA11에서는 활성화되지 않습니다. QA10의 8개 실제 geometry 표본을 새 QA11 측정으로 전용하지 않습니다. QA11의 목적은 실제 이동·사격·재장전 후 준비 사격 및 새 프레이밍 확인입니다.

변경 전 분리 렌더 비교의 0.12/0.20/0.50 단계에서 중심 반경16px의 모델 픽셀 수는 각각 0→0, 756→439, 191→0(797px 중)입니다. 0.20 단계 가림은 남으며 전체 시간축·다른 화면비·정확한 손 접촉을 통과 처리하지 않습니다. 단계0.12의 원래 잔차는 전체 탄창 목표를 사용한 진단 제한이 있어 손 IK 판정에서 제외합니다.

새 소스 freeze, 원래 UTC와 단조 시계가 있는 자원 사용 창, 입력 감사와 CAS 복원, 별도 출력 `D:/codex/q11`, 기존키 서명·APK 전체 readback을 사용합니다. 암호·키 내용 조회·복사·업로드와 외부 APK 업로드는 하지 않습니다. 실제 결과는 새 외부 검증 자료 및 후속 기록에 남깁니다.
