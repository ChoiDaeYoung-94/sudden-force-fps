# 재장전 중 소총의 중앙 시야 가림 줄이기

Refs #410

`PlayerLocomotionPresentation`의 재장전 위치 보정에서 왼쪽으로 최대 4cm 당기던 X 항만 제거했습니다. Y 높이, 탄창 단계, 회전, 손 IK, 재장전 시간 및 사격 판정은 그대로입니다. 손 가중치가 0인 대기·일반 사격·재장전 종료 시점에는 이 항의 전후 차이가 없습니다.

## 변경 전 비교와 선택 근거

- QA10 실제 테스트폰 영상에서 이동, 7발 발사, 탄약 30→23, 재장전 1.6초→0.1초→30을 확인했습니다. 이 영상은 새 변경의 실행 증거가 아닙니다.
- 같은 QA10 소스의 QA 비활성 Editor에서 분리된 복제 모델을 동일 카메라로 렌더링했습니다. 입력 에셋·공개 소스 4135개를 보존했고 새 제품 소스는 적용하지 않은 비교입니다.
- 재장전 단계 0.12/0.20/0.50에서 화면 중심 반경 16px의 모델 픽셀 수(총 797px)는 왼쪽 당김 제거 전후 각각 0→0, 756→439, 191→0이었습니다. 단계 0.20의 중앙 가림은 여전히 남습니다. 세 단계만의 정적 비교이며 전체 애니메이션·다른 해상도·사격 판정 통과가 아닙니다.
- 별도로 시험한 Y 높이 0.14→0.10 후보는 중심 가림이 191→756으로 증가하여 채택하지 않았습니다.
- 단계 0.12의 기존 손 잔차 지표는 혼합 손 목표가 아닌 전체 탄창 목표로 계산됐으므로 IK 성공·실패 판정에서 제외합니다. 실제 PNG와 원래 보고서는 수정하지 않았습니다.

로컬 근거는 `D:/codex/validation/sudden-force-fps/20261117-resume/reload-isolated-render-preparation01/`입니다. 3단계 실제 보고서 SHA256은 `77442AE8CF7BE926D841D2A44E227B20C72A1DE179D0AA03A2C3AF5D2C204F23`, 독립 화면 검토 보고서는 `24AE7E39AB4136959010E8F53F7A468B34AB35ED00987826DC69A7EB217DE591`입니다.
