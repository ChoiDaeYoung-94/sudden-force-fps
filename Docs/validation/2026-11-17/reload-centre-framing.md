# 재장전 중 소총의 중앙 시야 가림 줄이기

Refs #410

`PlayerLocomotionPresentation`의 재장전 위치 보정에서 왼쪽으로 최대 4cm 당기던 X 항을 제거하고, 좌우 회전각을 −25°에서 −12°로 줄였습니다. 재장전 중 총과 손이 중앙 조준점을 가리는 현상을 줄이는 변경입니다. Y 높이, 롤, 탄창 단계와 손 IK 가중치, 재장전 시간 및 사격 판정은 기존 값을 사용합니다. 아래 QA11 기록은 X 항 제거까지 포함한 중간 빌드의 결과이며, 최종 두 변경의 실기 결과는 QA12 절에 기록합니다.

## 변경 전 비교와 선택 근거

- QA10 실제 테스트폰 영상에서 이동, 7발 발사, 탄약 30→23, 재장전 1.6초→0.1초→30을 확인했습니다. 이 영상은 새 변경의 실행 증거가 아닙니다.
- 같은 QA10 소스의 QA 비활성 Editor에서 분리된 복제 모델을 동일 카메라로 렌더링했습니다. 입력 에셋·공개 소스 4135개를 보존했고 새 제품 소스는 적용하지 않은 비교입니다.
- 재장전 단계 0.12/0.20/0.50에서 화면 중심 반경 16px의 모델 픽셀 수(총 797px)는 왼쪽 당김 제거 전후 각각 0→0, 756→439, 191→0이었습니다. 단계 0.20의 중앙 가림은 여전히 남습니다. 세 단계만의 정적 비교이며 전체 애니메이션·다른 해상도·사격 판정 통과가 아닙니다.
- 별도로 시험한 Y 높이 0.14→0.10 후보는 중심 가림이 191→756으로 증가하여 채택하지 않았습니다.
