## 기기별 실행

| 기기와 앱 | 조작과 관측 |
| --- | --- |
| A17 일반 36, PC Editor | 실제 Photon 2인 경기에서 고정 사격 및 이동 중 FIRE를 검증했습니다. 이동 사격 14발의 서버 발사 tick에 이동 입력이 함께 있었습니다. 이동 중 재장전 직후와 별도 재장전 62/128 tick 시점에 Editor에서 상대 사격 입력을 통제해 사망을 관측했고, 후자의 새 생명은 HP 100·탄약 30으로 돌아왔습니다. 기본 2340×1080과 1920×1080 실제 경기에서 조준점 중심은 각각 (1170, 540), (960, 540)이었습니다. Android 카메라 광선과 같은 프레임의 탄착은 후속입니다. [재장전 검증](https://github.com/ChoiDaeYoung-94/sudden-force-fps/issues/188) · [조준점 검증](https://github.com/ChoiDaeYoung-94/sudden-force-fps/issues/401) |
| A17 일반 36 방장, PC Editor 손님 | 2 대 2 방의 단독·빈 팀·상대 미준비 조건에 각 안내가 표시됐습니다. 팀 변경 시 READY가 해제됐습니다. 양 팀 준비 후 방장이 START를 연속 두 번 눌렀을 때 손님 Runner가 유지되고 경기 씬 로드는 한 번, 서로 다른 게임 캐릭터는 두 명이었습니다. [방과 채팅 검증](https://github.com/ChoiDaeYoung-94/sudden-force-fps/issues/163) |
| LD3 일반 36 | 기존 앱의 로그인 재시도 후 로비에 도달하지 못했습니다. |
| LD5 일반 37 | 별도 테스트 인증서로 설치했습니다. 동일 인스턴스에서 36과 37의 로그인 안내를 비교하고, 37의 Retry 이후 Google 계정 입력 화면을 확인했습니다. |
| LD6 일반 38 | 전용 인스턴스에서 로컬 테스트 APK를 설치했습니다. 초기에는 검은 화면이었고 비교용 37에서도 재현됐습니다. 4 vCPU·4096 MiB로 재시작한 뒤 38의 Quad D 인트로와 Retry → Google 계정 입력 화면을 확인했습니다. 같은 인스턴스의 2 vCPU·4096 MiB 대조에서도 인트로와 Retry에 도달했습니다. 초기 검은 화면의 원인 분리와 실제 계정 인증은 후속입니다. 비교용 37을 제거한 뒤 앱 목록에서 일반 38을 확인했습니다. |
| A17 코드 38 별도 ID `com.AeDeong.SuddenForceFPS.splashcheck` | 기존 일반 36을 보존하려고 앱 ID를 분리했습니다. 엔진·데이터 항목 21개가 일반 38과 일치합니다. 인트로와 Retry를 관측했고 시험 후 임시 앱을 제거해 원래 게임 관련 네 패키지의 버전·앱 UID·설치/갱신 시각이 일치함을 확인했습니다. 이 표본은 일반 38 덮어쓰기·인증·경기 검증에서 제외합니다. |

A17 일반 36에서 Android 재생 출력을 녹음했습니다. 원격 좌우 각 3m·12m에서 발생시킨 12발의 사격은 가까운 쪽 채널이 컸고, 12m 쪽의 큰 채널은 3m보다 약 10.8 dB 작았습니다. 재장전도 같은 방향·거리 경향을 보였습니다. 발소리는 걸음 효과음군 파형과 맞는 후보로 분류했습니다. 실제 스피커 청취는 별도입니다.

## 패키지 대조

- 37과 38 각각 APK·AAB의 ARM64 네이티브 라이브러리 7개와 정적 정렬을 확인했습니다. 각 심볼 묶음은 6개이며 `libnanosockets.so`의 대응 심볼은 미확보입니다. 실제 16KB 환경 실행은 후속입니다.
- 38의 원본 BuildReport와 빌드 시 집계를 대조했습니다. 6,860행에서 공개 소스 경로 2,810개의 항목 수·바이트 수가 일치합니다. 공개 경로 집계 밖의 36행은 Unity 내장 리소스 26, 내장 표기 3, PreloadData 6, Quad D 영상 1입니다. APK·AAB의 `assets/bin/Data/sharedassets0.resource`는 고정 원본과 88,032바이트 전체가 일치합니다. AAB의 모듈 접두어는 `base/`입니다.
- 38의 두 패키지에 들어간 에셋 고지 전문 730,323바이트와 이모티콘 글꼴 아틀라스 262,144바이트를 소스와 대조했습니다. 외부 에셋의 전체 이용 권리·취득 자료 검수는 열려 있습니다. [에셋과 고지 검증](https://github.com/ChoiDaeYoung-94/sudden-force-fps/issues/42)
- 배포 서명과 Play 설치·업데이트, 등록 테스터 인증은 이 로컬 검증에 포함되지 않습니다. 마지막 확인 이력은 내부 트랙 코드 34/release 12입니다.
