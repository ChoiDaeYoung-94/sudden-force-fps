# 오른쪽 옆걸음 접지 보정 검증

## 클립과 재생 조건

`WalkRightGrounded.anim`은 양 팀이 공유하는 `Raw/WalkRight.anim`의 파생 클립입니다. Unity 6000.3.25f1에서 원본을 복제하고 120Hz로 한 주기의 160개 위상과 반복 경계를 샘플링했습니다. 원본 48개 Transform 회전 곡선 중 양쪽 허벅지·종아리·발목 네 성분씩 24개를 다시 구웠습니다. 나머지 24개 곡선의 키와 접선, 4/3초 길이, 반복 설정은 원본과 같습니다.

- 각 위상에서 실제 부츠 메시를 스키닝한 뒤 좌우 각각 352개 정점의 최저점을 구합니다. 두 발 중 낮은 밑창의 목표는 캡슐 바닥 아래 15.15mm입니다. 실제 평지에서 관측한 캡슐과 지면 간격 0~30.3mm의 중간값입니다.
- 보정은 발목 수평 좌표와 발 방향을 유지한 채 수직 목표에 두 다리 관절을 맞춰 클립에 기록합니다. 두 밑창의 높이 차가 15~85mm일 때 높은 발의 보정량을 부드럽게 줄입니다. 85mm 이상인 발은 원래 회전을 사용합니다. 인접 쿼터니언의 부호를 일치시킨 뒤 양쪽 이웃 위상으로 반복 경계의 접선을 구합니다.
- 재생 시 기존 그래프에서 오른쪽 걷기 가중치만 나눠 씁니다. 오른쪽 속도 성분이 전체 수평 성분 절댓값 합의 절반 이하이면 원본을 사용합니다. 그 이상이면 오른쪽으로 갈수록 보정 비율이 커집니다. 달리기 혼합에서 오른쪽 걷기 비중이 줄면 보정도 줄어듭니다.
- 보정 비중이 있을 때만 캐릭터가 속한 물리 씬에서 WorldGeometry 아래 방향 레이를 한 번 검사합니다. 지면 기울기 2~5도, 원점에서 지면까지의 수직 간격 35~90mm에서 원본으로 전환합니다. 지면을 놓치거나 보정 클립을 읽을 수 없는 경우에도 원래 보행을 재생합니다. 실행 중 IK 계산이나 네트워크 상태 추가는 없습니다.

## 재현 조건과 관측값

1. 일반판 A17을 호스트로 Desert House 2인 방을 생성하고 변경 소스의 Editor를 게스트로 참가시킵니다. A17에서 평지에 서서 오른쪽 걷기를 세 번 입력하고 사이에 왼쪽으로 돌아옵니다.
2. 게스트의 LateRender 이후 현재 생명과 대응되는 원격 캐릭터의 `SK_Military_Boots3`를 `BakeMesh`로 읽습니다. 양 발 최저 정점과 캡슐 바닥에서 같은 평평한 WorldGeometry를 맞혔고 로컬 속도 4.8~5.1m/s인 표본만 비교합니다. 단위는 실제 월드 좌표의 cm입니다.
3. 변경 전 별도 경기 29프레임에서 낮은 쪽 밑창은 −2.208~+5.635cm, 변경 후 96프레임에서 +1.433~+1.593cm였습니다. 양쪽 모두 16개 위상 구간을 모두 포함하고 캡슐 바닥과 지면 간격은 3.027cm였습니다. −1cm 미만 표본은 3→0, +3cm 초과 표본은 10→0입니다.
4. 별도 프리팹 비교에서는 12개 속도·방향마다 321개 위상을 검사했습니다. 두 팀의 결과가 일치하며 정지, 전·후·좌 걷기, 45도 전·후 대각선, 순수 오른쪽 달리기의 발 위치와 여섯 관절 회전 표본은 원본과 같습니다. 오른쪽 걷기 한 주기에서 발목 수평 위치의 최대 차이는 0.04mm 미만입니다.
5. 격리된 물리 프리뷰에서 pitch와 roll 각각 −10, −5, −3.5, 0, +3.5, +5, +10도 및 캡슐 간격 0, 30.3, 65, 140mm를 조합했습니다. 56개 조건 중 보정 비율 0인 38개에서는 각 160개 위상의 실제 밑창 높이 표본이 원본과 일치했습니다.

실제 경기는 A17의 입력과 Editor의 원격 표현을 검증합니다. 프리뷰의 경사판 측정은 실제 맵 경사 주행이나 Android에서 그린 상대 화면과 구분합니다.
