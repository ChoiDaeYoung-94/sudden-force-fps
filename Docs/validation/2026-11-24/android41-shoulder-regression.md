# Android 코드 41과 어깨 자세 비교 재현

Unity 6000.3.25f1에서 일반 패키지 `com.AeDeong.SuddenForceFPS` 1.0.200(41)을 생성했다. 일반판 소스 `a544841e02ffe703e0c2864a481004d2d8cc0242`와 A17 자세 시험의 기반인 병합 커밋 `3b6732b3ea3d326ceb8bc95b50e01bb321c310b5`는 Git 트리가 같다. 일반판은 Intro·Login·Lobby·Room·DesertHouse 다섯 씬을 포함한다. Unity 내보내기 오류 0건, 경고 68건이며 Gradle release 빌드 종료 코드는 0이다. 내보내기 뒤 일반판과 별도 시험판 작업 폴더 각각에서 추적 파일 4,145개의 원래 바이트를 확인했다.

## 패키지 확인

1. `bundletool validate`와 manifest에서 최소 API 25·대상 API 36·ARM64를 확인하고, APK와 AAB에서 네이티브 라이브러리 7개를 추출해 해시와 ELF 정렬을 확인한다. APK의 ZIP 정렬 검사도 통과했다. ARM64 심볼 6개를 식별했고 `libnanosockets.so` 심볼은 확보하지 못했다.
2. A17에서 읽은 기기 사양으로 일반 AAB의 분할 APK를 생성했다. base 모듈의 기본 APK와 ARM64 구성 분할 APK을 합치면 일반 AAB의 네이티브 라이브러리 7개와 에셋 14개의 바이트가 전부 일치한다. 기기 페이지 크기는 4,096바이트였다. 이 확인 범위는 분할 APK 생성과 바이트 대조다.
3. 빌드 보고서의 6,861행에서 공개 경로는 2,811개였다. 경로 밖 36행은 Unity 내장 리소스 26개·내장 이름 3개·preload 6개·Quad D 영상 1개다. APK·AAB 안에서 회사 인트로 영상 88,032바이트와 배포 고지 원문을 확인했다. 이 검사는 각 에셋의 이용 권한 승인을 포함하지 않는다.

4. APK 143개·AAB 151개의 ZIP 엔트리와 각 UnityFS의 압축 해제 바이트에서 지정한 서명 키 파일명, PEM 개인 키 블록과 GitHub 토큰 형식을 검사했다. 해당 패턴 검출은 0건이었다. 일반 비밀번호·임의 형식 PlayFab 키와 Git 이력은 이 산출물 검사 범위 밖이다.

## LDPlayer 일반판 업데이트

2 vCPU·4,096 MiB의 전용 LD7에서 별도 삭제·초기화 명령 없이 기존 코드 40을 로컬 테스트 서명의 41로 업데이트했다. `apksigner`의 v2 검사와 일반 무서명 APK 엔트리 143개의 원본 바이트를 대조했다. 콜드 시작 영상 796프레임에서 Quad D의 초반·형성·완성 구간을 확인했다. 원본 대조 평균은 0.994였다. 인트로 뒤 Google Play Games의 Retry 안내를 화면에서 확인했고 설치를 보존한 채 인스턴스를 종료했다. 정식 서명과 Play 설치는 별도 검증 대상이다.

## A17 어깨 비교

1. SM-A175N에서 일반 코드 36을 보존하고 별도 앱 ID의 단일 씬 시험 APK를 설치한다. Fusion Single의 Blue·Red 프리팹 각각에서 기존 메시 표시와 제품의 어깨 보정 표시를 같은 상대 카메라로 비교한다. 기존 표시 대조군은 선택적 소총 메시 보정을 연결하는 부품 이름을 스폰 직전 바꿔 구성했다.
2. 수평·상하 15도·앉기·오른쪽 걷기 합성 입력 다섯 조건으로 20단계를 검사했다. 단계당 LateUpdate 자세 평가 18회와 기기 화면 1장을 수집했다. 2340×1080 OpenGL ES 3에서 기존 180개와 보정 180개를 기록했다. 매 표본에서 HitboxCapture를 직접 호출한 뒤 소총 뒤 부품의 로컬 위치가 0, 스케일이 1로 돌아왔는지 벡터 거리 0.000317 이내로 대조했다. 손목 목표 오차 최댓값은 0.0006mm였다. 각 단계의 표시 이름과 휴대폰 화면 20장을 대조했다. 앉은 캐릭터는 화면 하단에서 일부 잘려 이 네 장으로 어깨 전체의 외형을 판단하기 어렵다. 처음에는 일곱 화면을 받은 뒤 기기 상태 확인이 끊겼다. 시험 앱을 정리하고 동일 APK를 다시 실행해 20단계를 마쳤다.
3. 별도 실제 온라인 경기에서는 A17 일반 코드 36의 원격 캐릭터를 Editor에서 관찰했다. 같은 틱·자세의 복장 표면을 기준으로 축 방향 겹침 중앙값은 서 있을 때 약 177mm에서 25.5mm로 줄었다. 전체 프리팹 회귀는 양 팀·서기/앉기·정지/걷기/달리기·171개 피치, 총 2,052조건이다. [변경과 독립 검토](https://github.com/ChoiDaeYoung-94/sudden-force-fps/pull/443)
4. A17 비교 후 시험 앱을 제거했다. 원래 네 패키지의 UID·버전·설치 및 갱신 시각이 같았고 일반 코드 36이 다시 앞에 표시됐다. 이 절차에서는 일반 코드 41의 계정 인증·실제 두 기기 경기·16KB 기기 실행을 확인하지 않았다.
