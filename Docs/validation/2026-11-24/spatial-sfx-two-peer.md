# 두 피어 경기의 총성·발소리·재장전 스테레오 검증

Unity 6000.3.25f1 Editor(소스 `6496ac89`)가 손님, Galaxy A17 일반 코드 36이 방장이었습니다. DesertHouse의 실제 2인 경기에서 휴대폰 터치로 사격·이동·재장전을 하고, Editor가 받은 상대 캐릭터의 게임 오디오를 48 kHz 스테레오 PCM으로 기록했습니다. 마이크 입력은 사용하지 않았습니다.

| 입력 | 확인한 동작 | 녹음 결과 |
| --- | --- | --- |
| 청취점 왼쪽 3 m에서 한 발 | 원격 사격 표시 1회 | 왼쪽이 오른쪽보다 약 23 dB 큼 |
| 오른쪽 3 m에서 한 발 | 원격 사격 표시 1회 | 오른쪽이 왼쪽보다 약 23 dB 큼 |
| 오른쪽 12 m에서 한 발 | 원격 사격 표시 1회 | 오른쪽 채널이 3 m 때보다 약 11 dB 낮음 |
| 청취점 왼쪽에서 걷기 | 원격 발걸음 3회, 사격 0회 | 발소리가 녹음됐고 왼쪽이 더 큼 |
| 오른쪽에서 재장전 | 재장전 입력 후 효과 누계 1회·탄약 30 관측 | 오른쪽에 재장전 소리가 녹음됨 |
| SFX 음량 0에서 오른쪽 3 m 사격 | 원격 사격 표시 1회 | 16비트 PCM 전체가 0. 종료 후 원래 음량·저장값 복원 |

거리는 수평 기준입니다. 청취점은 지면에서 1.2 m 높이에 고정했습니다. 수치는 매 10 ms의 RMS 중 최대값을 채널별로 비교했습니다. 이 측정의 범위는 게임 믹서의 출력입니다. 휴대폰 스피커 음질, 실제 터치부터 스피커 출력까지의 지연, 장애망에서의 중복 재생은 추가 검수 항목입니다.

재현할 때는 같은 방의 두 피어를 사용해 멈춘 상대의 왼쪽·오른쪽과 거리를 바꾸고, 매번 휴대폰에서 한 발만 발사합니다. 이동과 재장전은 별도 구간에서 실행합니다. 측정용 청취점을 쓰는 동안 로컬 캐릭터가 활성화하는 리스너도 그 청취점으로 연결해 활성 `AudioListener`가 하나인지 확인합니다. 리스너가 2개였던 첫 측정과 벽에 막혀 발걸음이 없었던 표본은 위 결과에서 제외했습니다. 시험 종료 후 원래 리스너와 음량을 복원했습니다.
